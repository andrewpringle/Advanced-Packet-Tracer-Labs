# Advanced-Packet-Tracer-Labs
This repo demonstrates 5 realistic small-scale Cisco Packet Tracer labs, with their own .pkt file and documentation. Each project also features controlled faults used for debugging and administration purposes.

All configurations, documentation, faults and recovery, server and host setup, SSH and CLI import, topology of the network (+ HTML file of logical connections, cabling, alongside the validation and verification of the Packet Tracer file are included in each project's respective folder.
