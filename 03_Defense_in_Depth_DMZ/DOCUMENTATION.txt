OPEN AND USE
1. Open 03_Defense_in_Depth_DMZ.pkt in Packet Tracer 9.0.1.
2. Allow link negotiation, STP, routing, HSRP and DHCP to converge.
3. On DHCP PCs, Desktop > IP Configuration > DHCP; renew if necessary.
4. Follow VERIFICATION.txt. Record actual outputs in your own evidence copy.
5. Save a baseline copy before FAULTS_AND_RECOVERY.txt exercises.
6. Reference CLI files are in configs/. From privileged EXEC use configure
   terminal, paste the configuration through end, then copy running-config
   startup-config. Do not paste the Server-PT settings as IOS commands.

DESIGN CORRECTIONS FROM THE SUPPLIED PROJECT
- Outside ACL now permits return TCP, ICMP replies/errors and approved public DNS replies to the PAT address. The original deny-all would have broken inside Internet tests.
- Removed ICMP echo permit to the TCP-only published NAT address: static PAT for ports 80/443 does not publish ICMP.
- DMZ ACL permits established HTTP/HTTPS and ICMP echo replies before denying new DMZ-to-inside flows; inside browsing of the DMZ server can now receive responses.
- Added PUBLIC-SRV on ISP1 Gi0/2, 192.0.2.0/24, for an actual external HTTP/DNS service target without disturbing the original external PC link.
- Raised logging trap to informational so severity-6 ACL events are eligible for supported event export. ISP /32 route to 203.0.113.10 via 203.0.113.2 is retained.

LAB LIMITS
ACLs here are stateless IOS ACLs. TCP established checks ACK/RST flags and is
not a stateful firewall. DNS/NTP/syslog are simulated services. Documentation
does not claim real Internet access, real packet capture or production security.
The configurations use example address ranges and shared training passwords.
Packet Tracer is a simulator: verify platform-specific DAI, SPAN, ACL logging,
IPv6/SDM and HSRP behavior using the commands in VERIFICATION.txt.

PACKET TRACER 9.0.1 COMPATIBILITY CORRECTION
Native open/save testing rejected ACL statements with the log suffix.
The suffix has been removed so the deny statements are actually installed.
Use show access-lists hit counters and Simulation Mode for ACL-deny evidence.
Syslog still covers supported interface/system/port-security events; ACL-deny
syslog export is not claimed. Never treat an unsupported log keyword as safe: it
can cause the entire deny ACE to be dropped when loading a configuration.

Static PAT syntax omits the unsupported extendable suffix so Packet Tracer installs both TCP mappings.
